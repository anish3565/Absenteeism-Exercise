# 📊 Absenteeism Exercise

This project analyzes employee absenteeism data to identify patterns and factors contributing to workplace absenteeism. Utilizing Python and Jupyter Notebook, the analysis aims to provide insights that can help organizations understand and address absenteeism issues.

## 🗂️ Repository Contents

- **Absenteeism Exercise- The Dataset.ipynb**: A Jupyter Notebook containing the data analysis process, including data loading, preprocessing, exploratory data analysis (EDA), and initial findings.
- **Absenteeism-data.csv**: The dataset used for analysis, containing records of employee absenteeism along with various related attributes.

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 🚀 Getting Started

### Prerequisites

Ensure you have the following installed:
- Python 3.x
- Jupyter Notebook
- Required Python libraries (listed below)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/anish3565/Absenteeism-Exercise.git
cd Absenteeism-Exercise
```

2. Create a virtual environment (optional but recommended):
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

3. Install the required packages:
```bash
pip install pandas numpy matplotlib seaborn jupyter
```

4. Launch Jupyter Notebook:
```bash
jupyter notebook
```

5. Open the notebook:
   - In the Jupyter interface, navigate to and open `Absenteeism Exercise- The Dataset.ipynb`.

## 📈 Analysis Overview

The analysis includes:
- Loading and exploring the absenteeism dataset.
- Data preprocessing and cleaning.
- Exploratory data analysis (EDA) to identify trends and patterns.
- Visualization of key findings.
